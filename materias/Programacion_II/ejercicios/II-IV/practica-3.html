📋 Enunciados y Actividades Prácticas ​

Objetivo ​

Aplicar los conceptos del Capítulo I, II y III de la Lectura 3. El objetivo es que aprendas a crear una estructura visual (HTML) y a darle estilos modernos, colores y responsividad (CSS). Dejaremos la consola atrás para adentrarnos en la Interfaz Gráfica (UI).

Tareas del Alumno ​

  1. Abre el archivo index.html dando doble clic sobre él en tu explorador de archivos. Verás la página en tu navegador web.
  2. Experimentar con CSS:
    • Abre css/styles.css y cambia el color principal del encabezado (.header-principal) a tu color favorito (puedes usar nombres en inglés como darkred o códigos Hexadecimales como #8e44ad).
    • Agranda el tamaño de fuente (font-size) del botón "Guardar Estudiante".
  3. Ampliar el HTML:
    • En index.html, dentro del formulario, agrega un nuevo campo (input) llamado "Edad" justo debajo de la Cédula. Asegúrate de ponerle su etiqueta <label>.
    • Modifica la tabla para incluir una nueva columna "Edad" y actualiza los datos "quemados" de ejemplo para que también muestren una edad.
  4. Redimensiona la ventana de tu navegador para que veas cómo el diseño pasa de dos columnas a una sola (Diseño Responsivo).

📄 css/styles.css ​

css
/* =========================================
   Estilos Base y Reset (Modelo de Caja)
========================================= */
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    background-color: #f4f7f6; /* Color de fondo claro */
    color: #333;
    line-height: 1.6;
}

/* =========================================
   Encabezado (Header)
========================================= */
.header-principal {
    background-color: #2c3e50; /* Azul oscuro elegante */
    color: white;
    text-align: center;
    padding: 2rem 1rem;
    box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

.header-principal p {
    color: #bdc3c7;
    font-size: 0.9rem;
    margin-top: 5px;
}

/* =========================================
   Contenedor Principal (Grid / Flexbox)
========================================= */
.contenedor {
    max-width: 1000px;
    margin: 2rem auto;
    padding: 0 1rem;
    
    /* Usamos Grid para poner las tarjetas lado a lado en pantallas grandes */
    display: grid;
    grid-template-columns: 1fr;
    gap: 2rem;
}

/* Responsive: Si la pantalla es mayor a 768px, dividir en 2 columnas */
@media (min-width: 768px) {
    .contenedor {
        grid-template-columns: 1fr 2fr; /* El form ocupa 1 parte, la tabla 2 partes */
    }
}

/* =========================================
   Tarjetas (Cards)
========================================= */
.tarjeta {
    background: white;
    border-radius: 8px;
    padding: 1.5rem;
    box-shadow: 0 4px 15px rgba(0,0,0,0.05);
}

.tarjeta h2 {
    color: #2c3e50;
    border-bottom: 2px solid #ecf0f1;
    padding-bottom: 0.5rem;
    margin-bottom: 1.5rem;
}

/* =========================================
   Formularios
========================================= */
.grupo-input {
    margin-bottom: 1rem;
}

label {
    display: block;
    margin-bottom: 0.3rem;
    font-weight: 600;
    font-size: 0.9rem;
}

input, select {
    width: 100%;
    padding: 0.8rem;
    border: 1px solid #ccc;
    border-radius: 4px;
    font-family: inherit;
}

input:focus, select:focus {
    outline: none;
    border-color: #3498db; /* Borde azul al hacer clic */
    box-shadow: 0 0 5px rgba(52, 152, 219, 0.3);
}

    width: 100%;
    padding: 0.8rem;
    background-color: #27ae60; /* Verde éxito */
    color: white;

}
