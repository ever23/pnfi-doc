📋 Enunciados y Actividades Prácticas ​

En esta práctica, exploraremos cómo los programas toman decisiones complejas combinando múltiples entradas y condiciones lógicas.

  1. Sistema de Control de Acceso a Evento Diseñe un programa que valide el acceso a un club. El sistema debe solicitar la edad del usuario y si posee una entrada (si/no).
  • Si es menor de 18 años: "Acceso denegado: Menor de edad".
  • Si es mayor de 18 y tiene entrada: "¡Bienvenido! Disfrute el evento".
  • Si es mayor de 18 pero NO tiene entrada: "Acceso denegado: Debe comprar su entrada en taquilla".
  • Desafío: Si el usuario tiene más de 60 años y tiene entrada, mostrar: "¡Bienvenido! Tiene acceso a la zona VIP".
  1. Calculadora de Nómina con Bonos y Deducciones Escriba un script que calcule el sueldo de un trabajador. Solicite el sueldo base y los años de antigüedad.
  • Si el trabajador tiene más de 5 años de antigüedad, se le suma un bono del 10% del sueldo base.
  • Si el sueldo final (después del bono) es superior a $500, se le aplica una retención de seguridad social del 4%. Muestre el desglose final: Sueldo base, monto del bono aplicado, monto de la retención y el sueldo neto a cobrar.
  1. Clasificador de Triángulos Cree un programa que solicite al usuario la medida de los tres lados de un triángulo. El sistema debe realizar lo siguiente:
  • Primero, verificar si los lados pueden formar un triángulo (la suma de dos lados siempre debe ser mayor al tercero).
  • Si es válido, clasificarlo como:
    • Equilátero: Los tres lados son iguales.
    • Isósceles: Dos lados son iguales.
    • Escaleno: Todos los lados son diferentes.
  1. Simulador de Inicio de Sesión y Retiro Desarrolle un sistema de cajero automático muy básico.
  • Defina un PIN constante (ej: 1234) y un saldo inicial (ej: $1000).
  • Solicite al usuario su clave.
  • Si la clave es correcta, pregunte el monto a retirar.
    • Si el monto es menor o igual al saldo, muestre: "Retiro exitoso. Su nuevo saldo es: [resultado]".
    • Si el monto supera el saldo, muestre: "Fondos insuficientes".
  • Si la clave es incorrecta desde el inicio, muestre: "Acceso bloqueado: Clave errónea".

🧠 Conceptos clave a aplicar: ​

  • Estructuras if / else if / else anidadas.
  • Operadores lógicos complejos: && (Y), || (O).
  • Uso de variables para mantener estados (ej: el saldo).

📝 Solucionario Lógico (Pseudocódigo / Metodología) ​

Este documento contiene la implementación lógica para los ejercicios de toma de decisiones avanzadas.

1. Control de Acceso (Condiciones Múltiples) ​

javascript
const prompt = require('prompt-sync')();

const edad = parseInt(prompt("Ingrese su edad: "));
const tieneEntrada = prompt("¿Tiene entrada? (si/no): ").toLowerCase();

if (edad < 18) {
    console.log("Acceso denegado: Menor de edad.");
} else {
    if (tieneEntrada === "si") {
        if (edad > 60) {
            console.log("¡Bienvenido! Tiene acceso a la zona VIP.");
        } else {
            console.log("¡Bienvenido! Disfrute el evento.");
        }
    } else {
        console.log("Acceso denegado: Debe comprar su entrada en taquilla.");
    }
}

2. Nómina con Bonos y Deducciones ​

javascript
const prompt = require('prompt-sync')();

const sueldoBase = parseFloat(prompt("Sueldo base ($): "));
const antiguedad = parseInt(prompt("Años de antigüedad: "));

let bono = 0;
if (antiguedad > 5) {
    bono = sueldoBase * 0.10;
}

const sueldoConBono = sueldoBase + bono;

let retencion = 0;
if (sueldoConBono > 500) {
    retencion = sueldoConBono * 0.04;
}

const sueldoNeto = sueldoConBono - retencion;

console.log("\n--- RECIBO DE PAGO ---");
console.log(`Sueldo Base: $${sueldoBase}`);
console.log(`Bono Antigüedad: $${bono}`);
console.log(`Retención (4%): $${retencion}`);
console.log(`TOTAL NETO: $${sueldoNeto}`);

3. Clasificador de Triángulos ​

javascript
const prompt = require('prompt-sync')();

const a = parseFloat(prompt("Lado A: "));
const b = parseFloat(prompt("Lado B: "));
const c = parseFloat(prompt("Lado C: "));

// Verificación de existencia de triángulo
if ((a + b > c) && (a + c > b) && (b + c > a)) {
    console.log("Es un triángulo válido.");
    
    if (a === b && b === c) {
        console.log("Clasificación: Equilátero");
    } else if (a === b || a === c || b === c) {
        console.log("Clasificación: Isósceles");
    } else {
        console.log("Clasificación: Escaleno");
    }
} else {
    console.log("Error: Los lados ingresados no pueden formar un triángulo.");
}

4. Simulador de Cajero (Lógica Anidada) ​

javascript
const prompt = require('prompt-sync')();

const PIN_CORRECTO = "1234";
let saldo = 1000;

const clave = prompt("Ingrese su clave secreta: ");

if (clave === PIN_CORRECTO) {
    console.log("Acceso concedido. Saldo actual: $" + saldo);
    const monto = parseFloat(prompt("¿Cuánto desea retirar?: "));
    
    if (monto > 0 && monto <= saldo) {
        saldo = saldo - monto;
        console.log("Retiro exitoso. Su nuevo saldo es: $" + saldo);
    } else if (monto > saldo) {
        console.log("Error: Fondos insuficientes.");
    } else {
        console.log("Monto inválido.");
    }
} else {
    console.log("Acceso bloqueado: Clave errónea.");
}

📄 ejercicio1_transporte.js ​

javascript
const prompt = require('prompt-sync')();

console.log("=== SISTEMA DE TARIFA DE TRANSPORTE PÚBLICO ===");
const tipoUsuario = parseInt(prompt("Tipo de usuario (1: Estudiante, 2: Docente/Personal, 3: Público General): "));
const turno = parseInt(prompt("Turno (1: Diurno, 2: Nocturno): "));

let tarifa = 0;

if (tipoUsuario === 1) {
    if (turno === 1) {
        const carnet = prompt("¿Posee carnet vigente? (si/no): ").toLowerCase();
        if (carnet === "si") {
            tarifa = 0.00;
            console.log("¡Beneficio aplicado! Pasaje exonerado por carnet estudiantil.");
        } else {
            tarifa = 0.50;
        }
    } else {
        tarifa = 0.50 * 1.20;
    }
} else if (tipoUsuario === 2) {
    tarifa = (turno === 1) ? 0.80 : 1.00;
} else if (tipoUsuario === 3) {
    tarifa = (turno === 1) ? 1.50 : 2.00;
} else {
    console.log("Error: Tipo de usuario inválido.");
}

if (tipoUsuario >= 1 && tipoUsuario <= 3) {
    console.log(`\n--- TARIFA A PAGAR ---`);
    console.log(`Monto total: $${tarifa.toFixed(2)}`);
}

📄 ejercicio3_microcredito.js ​

javascript
const prompt = require('prompt-sync')();

console.log("=== SIMULADOR DE MICROCRÉDITOS SOCIOPRODUCTIVOS ===");
const montoSol = parseFloat(prompt("Monto solicitado ($): "));
const ingresos = parseFloat(prompt("Ingresos mensuales demostrables ($): "));
const aval = prompt("¿Posee aval del consejo comunal? (si/no): ").toLowerCase();

if (montoSol > 2000 && aval !== "si") {
    console.log("Crédito DENEGADO: Los montos superiores a $2,000 exigen aval obligatorio del consejo comunal.");
} else {
    const umbral = montoSol * 0.30;
    const umbralRevision = montoSol * 0.15;
    
    if (ingresos >= umbral) {
        console.log("Crédito APROBADO: Cuenta con suficiente capacidad de pago.");
    } else if (ingresos >= umbralRevision) {
        console.log("Crédito SUJETO A REVISIÓN: Requiere co-fiador por capacidad de pago moderada.");
    } else {
        console.log("Crédito DENEGADO: Insuficiencia de ingresos mensuales.");
    }
}

📄 ejercicio4_impuestos.js ​

javascript
const prompt = require('prompt-sync')();

console.log("=== CALCULADORA DE IMPUESTOS MUNICIPALES ===");
const categoria = parseInt(prompt("Categoría de actividad (1: Comercial, 2: Industrial, 3: Servicios): "));
const ingresosBrutos = parseFloat(prompt("Ingrese los ingresos brutos anuales ($): "));

let impuesto = 0;
let tasaAplicada = "0%";

if (categoria === 1) {
    if (ingresosBrutos <= 10000) {
        impuesto = ingresosBrutos * 0.02;
        tasaAplicada = "2%";
    } else {
        impuesto = (10000 * 0.02) + ((ingresosBrutos - 10000) * 0.04);
        tasaAplicada = "2% hasta $10,000 y 4% sobre el excedente";
    }
} else if (categoria === 2) {
    impuesto = ingresosBrutos * 0.05;
    tasaAplicada = "5%";
} else if (categoria === 3) {
    if (ingresosBrutos < 5000) {
        impuesto = 0;
        tasaAplicada = "Exento (0%)";
    } else {
        impuesto = ingresosBrutos * 0.03;
        tasaAplicada = "3%";
    }
} else {
    console.log("Categoría inválida.");
}

if (categoria >= 1 && categoria <= 3) {
    console.log("\n--- RECIBO DE IMPUESTO MUNICIPAL ---");
    console.log(`Categoría: ${categoria}`);
    console.log(`Ingresos Brutos: $${ingresosBrutos.toFixed(2)}`);
    console.log(`Tasa Aplicada: ${tasaAplicada}`);
    console.log(`TOTAL IMPUESTO: $${impuesto.toFixed(2)}`);
}

📄 ejercicio5_laboratorio.js ​

javascript
const prompt = require('prompt-sync')();

console.log("=== CONTROL DE ACCESO A LABORATORIOS ===");
const credencial = prompt("¿Posee credencial digital activa? (si/no): ").toLowerCase();
const horarioHabil = prompt("¿Se encuentra en horario hábil (Lun-Vie 8am-5pm)? (si/no): ").toLowerCase();
const autorizacion = prompt("¿Cuenta con autorización firmada del Profesor Asesor? (si/no): ").toLowerCase();

if (credencial === "si" && horarioHabil === "si") {
    console.log("Acceso CONCEDIDO: Bienvenido al Laboratorio.");
} else if (credencial === "si" && horarioHabil !== "si" && autorizacion === "si") {
    console.log("Acceso CONCEDIDO CON PERMISO ESPECIAL: Fuera de horario con autorización.");
} else {
    console.log("Acceso DENEGADO.");
    if (credencial !== "si") {
        console.log("Motivo: Credencial digital inactiva o inexistente.");
    } else if (horarioHabil !== "si" && autorizacion !== "si") {
        console.log("Motivo: Fuera de horario hábil y sin autorización firmada del Profesor Asesor.");
    }
}
